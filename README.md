# WattNow ⚡

极简、高刷新率的 Android 实时充电功率监测与历史记录工具。

---

## 核心特性

- **实时功率监测**：秒级高频读取系统底层电池充放电数据，动态展示当前功率（W）、电流（A）、电压（V）及电池电量（%）。
- **快充协议智能推导 (V1.2.4 新增)**：自研 `ChargingProtocolDetector` 多级推导引擎，结合底层硬件协商参数（`max_charging_current` / `max_charging_voltage`）、机型架构与 Peak-Hold 会话峰值保持算法，免 Root 精准识别 **小米澎湃秒充 (67W / 90W / 120W)**、**USB-PD 3.0 / PPS 极速快充**、**高通 QC 4+ / QC 3.0**、**DCP 标充 10W** 与 **无线秒充**。
- **全图表横轴时间轴与触摸拖拽查点 (V1.2.3 新增)**：全量图表（实时主页、曲线对比、历史记录）统一采用“已运行分钟”标准横坐标；支持手指触摸拖拽十字虚线准星与毛玻璃悬浮卡片实时查点。
- **锁屏后台采样看门狗与自愈机制 (V1.2.3 新增)**：独立协程调度域与协议握手防抖，彻底消除息屏休眠与切后台引起的采样中断。
- **全链路协议视觉联动 (V1.2.4 新增)**：主监控卡片专属协议芯片光晕、下拉通知栏常驻卡片、历史列表彩色协议胶囊与详情页深度指标全面联动。
- **设备温度与热状态监控**：免 Root 原生感知系统热节流状态（Thermal Status）与热余量（Thermal Headroom）；自适应探测 CPU 核心、GPU 核心及机身外壳（Skin）温度。
- **功率与温度双曲线联动**：支持“综合叠图对比”、“仅功率”、“仅温度”自由切换，结合水平中点切线三次贝塞尔平滑样条（Cubic Bezier Spline）算法。
- **全新 Apple 磨砂玻璃质感与双模式**：严格遵循 Apple HIG 规范，卡片全量采用 16pt 经典连续平滑圆角（Squircle）与超透磨砂材质；支持普通浅色模式与深夜深色模式。
- **空间悬浮毛玻璃胶囊底栏**：自适应紧凑包裹的悬浮胶囊，无下划线纯净磨砂滑块切换「实时 / 曲线 / 记录」。
- **充电即显、拔线即消**：仅在充电时展示通知栏与锁屏功率卡片，拔线即刻自动撤销通知并释放服务，不充电时零通知零打扰。

## 适配品牌与硬件平台

| 品牌 / 平台 | 适配系统 | 适配说明 |
| :--- | :--- | :--- |
| **小米 / Redmi** | **HyperOS / MIUI** | 深度适配澎湃秒充识别、锁屏常驻、通知中心卡片与免 Root Thermal Zone 温度探测，已在主流品牌旗舰真机验证 |
| **高通骁龙平台** | **Snapdragon 全系** | 专门针对高通骁龙旗舰 PMIC 芯片进行微安转换修正、QC 协议推导与突跳硬滤波 |
| **OPPO / 一加 / Realme** | **ColorOS** | 适配标准电池广播与低功耗前台服务 |
| **vivo / iQOO** | **OriginOS** | 支持沉浸式状态栏与后台静默保活 |
| **荣耀 / 华为** | **MagicOS / HarmonyOS** | 兼容标准 Android BatteryManager 接口与快充推导 |
| **原生 / 其他** | **Android 8.0 - 16+** | 遵循现代 Android 前台服务与自适应图标规范 |

> **使用提示**：为保证后台常驻与断充记录的完整性，建议在系统设置中将 WattNow 的「省电策略/电池优化」设为「无限制」，并允许「后台自启动」。

## 编译与安装

```bash
# 安装已编译完成的正式版 V1.2.4 安装包：
adb install -r WattNow-v1.2.4.apk

# 或编译 Release / Debug APK：
./gradlew assembleRelease
./gradlew assembleDebug
```
