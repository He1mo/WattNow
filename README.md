# WattNow ⚡

极简、高刷新率的 Android 实时充电功率监测与历史记录工具。

---

## 核心特性

- **实时功率监测**：秒级高频读取系统底层电池充放电数据，动态展示当前功率（W）、电流（A）、电压（V）及电池电量（%）。
- **设备温度与热状态监控 (V1.1 新增)**：免 Root 原生感知系统热节流状态（Thermal Status）与热余量（Thermal Headroom）；自适应探测 CPU 核心、GPU 核心及机身外壳（Skin）温度。
- **功率与温度双曲线联动 (V1.1 新增)**：支持“综合叠图对比”、“仅功率”、“仅温度”自由切换，结合水平中点切线三次贝塞尔平滑样条（Cubic Bezier Spline）算法，彻底消除折角生硬感。
- **全新 Apple 磨砂玻璃质感与双模式 (V1.2 新增)**：严格遵循 Apple HIG 规范，卡片全量采用 16pt 经典连续平滑圆角（Squircle）与超透磨砂材质；支持普通浅色模式与深夜深色模式。
- **空间悬浮毛玻璃胶囊底栏 (V1.2 新增)**：告别传统贴底导航，采用自适应紧凑包裹的悬浮胶囊，无下划线纯净磨砂滑块切换「实时 / 曲线 / 记录」。
- **内容优先直出布局 (V1.2 新增)**：彻底移除顶部冗余 App 标题，黄金空间 100% 留给核心功率与参数。
- **纯粹时序双曲线展示 (V1.2 新增)**：去除假交点噱头，真实平滑样条直观呈现功率与温度双轨走势。
- **充电全周期记录**：自动识别充电过程，高保真记录全程功率与温度变化，计算温升幅度（ΔT）、均值功率与充入能量（Wh）。
- **设备温度与多温区监控**：免 Root 原生感知系统热节流状态（Thermal Status）与热余量（Thermal Headroom）；自适应探测 CPU 核心、GPU 核心及机身外壳（Skin）温度。
- **静默后台常驻**：专用低干扰常驻通知，充电中实时刷新，拔线后静默待机，点开 App 不弹横幅打扰。

## 适配品牌与硬件平台

| 品牌 / 平台 | 适配系统 | 适配说明 |
| :--- | :--- | :--- |
| **小米 / Redmi** | **HyperOS / MIUI** | 深度适配锁屏常驻、通知中心卡片与免 Root Thermal Zone 温度探测，已在主流品牌旗舰真机验证 |
| **高通骁龙平台** | **Snapdragon 全系** | 专门针对高通骁龙旗舰 PMIC 芯片进行微安转换修正与突跳硬滤波 |
| **OPPO / 一加 / Realme** | **ColorOS** | 适配标准电池广播与低功耗前台服务 |
| **vivo / iQOO** | **OriginOS** | 支持沉浸式状态栏与后台静默保活 |
| **荣耀 / 华为** | **MagicOS / HarmonyOS** | 兼容标准 Android BatteryManager 接口 |
| **原生 / 其他** | **Android 8.0 - 16+** | 遵循现代 Android 前台服务与自适应图标规范 |

> **使用提示**：为保证后台常驻与断充记录的完整性，建议在系统设置中将 WattNow 的「省电策略/电池优化」设为「无限制」，并允许「后台自启动」。

## 编译与安装

```bash
# 安装已编译完成的正式版 V1.2 安装包：
adb install -r WattNow-v1.2.apk

# 或编译 Release / Debug APK：
./gradlew assembleRelease
./gradlew assembleDebug
```
