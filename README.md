# WattNow ⚡

极简、高刷新率的 Android 实时充电功率监测与历史记录工具。

---

## 核心特性

- **实时功率监测**：秒级高频读取系统底层电池充放电数据，动态展示当前功率（W）、电流（A）、电压（V）、电池电量（%）及温度（°C）。
- **动态波形图**：实时渲染最近 30 秒充电功率走势图，直观掌握快充阶段。
- **充电会话记录**：自动识别并完整记录每次充电全过程，提供平均功率、峰值功率、充入能量（Wh）及全周期折线图。
- **静默后台常驻**：专用低干扰常驻通知，充电中实时刷新，拔线后静默待机，点开 App 不弹横幅打扰。
- **沉浸式深色模式**：全局 Edge-to-Edge 全屏设计，完美适配顶部刘海/打孔屏与底部手势导航条。

## 适配品牌与硬件平台

| 品牌 / 平台 | 适配系统 | 适配说明 |
| :--- | :--- | :--- |
| **小米 / Redmi** | **HyperOS / MIUI** | 深度适配锁屏常驻与通知中心卡片，已在主流品牌旗舰真机验证 |
| **高通骁龙平台** | **Snapdragon 全系** | 专门针对高通骁龙旗舰 PMIC 芯片进行微安转换修正与突跳硬滤波 |
| **OPPO / 一加 / Realme** | **ColorOS** | 适配标准电池广播与低功耗前台服务 |
| **vivo / iQOO** | **OriginOS** | 支持沉浸式状态栏与后台静默保活 |
| **荣耀 / 华为** | **MagicOS / HarmonyOS** | 兼容标准 Android BatteryManager 接口 |
| **原生 / 其他** | **Android 8.0 - 16+** | 遵循现代 Android 前台服务与自适应图标规范 |

> **使用提示**：为保证后台常驻与断充记录的完整性，建议在系统设置中将 WattNow 的「省电策略/电池优化」设为「无限制」，并允许「后台自启动」。

## 编译与安装

```bash
# 编译 Debug APK
./gradlew assembleDebug

# 或直接安装根目录已编译完成的安装包：
adb install -r WattNow-debug.apk
```
